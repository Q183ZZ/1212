# 耀宝 Bluetooth 音箱连接线路（V1.1）

目标：在不增加手机 App 的前提下，让耀宝本体同时承担 AI 导航、语音助手和标准 Bluetooth 音箱功能。

## 1. 推荐架构

```text
手机/平板
   │
   │ Bluetooth A2DP / AVRCP
   ▼
┌──────────────────────────────┐
│ Orange Pi Zero（Linux）       │
│ BlueZ Bluetooth Stack         │
│ PipeWire / PulseAudio         │
└──────────────┬───────────────┘
               │ PCM / I2S / USB Audio
               ▼
      ┌──────────────────┐
      │ Class-D 功放模块 │
      │ 2 × 2W～5W       │
      └───────┬─────┬────┘
              │     │
              ▼     ▼
          左扬声器  右扬声器
          8Ω/2W     8Ω/2W

3.7V 锂电池 → 电源管理/保护 → 5V/3.3V 电源轨
                                  ├→ Orange Pi
                                  ├→ GPS GT-U7
                                  ├→ 功放
                                  └→ 屏幕/麦克风等
```

## 2. Bluetooth 部分

优先使用 Orange Pi 主板自带 Bluetooth，由 Linux BlueZ 管理。

如果最终选用的 Orange Pi Zero 具体 SKU 没有板载 Bluetooth，则增加一个 USB Bluetooth 5.x 模块，直接插入主板 USB 接口。不要把 Bluetooth 模块当成必须焊死在球壳里的独立射频板，先保留 V1 的可替换性。

Bluetooth 负责的是无线音频链路，不直接推动扬声器。手机的 A2DP 音频进入 Linux 音频系统后，再送到功放。

## 3. 音频功放线路

推荐使用独立 Class-D 双声道功放模块，而不是直接让 Orange Pi GPIO/普通音频口带扬声器。

推荐信号关系：

- Orange Pi 音频输出 → 功放输入 L/R
- 功放 L+ / L− → 左侧 8Ω/2W 扬声器
- 功放 R+ / R− → 右侧 8Ω/2W 扬声器
- 功放 GND → 系统电源 GND
- 功放电源 → 稳压后的 5V 电源轨

如果功放模块要求模拟 Line-In，就使用主板可用的 USB Audio 声卡/Codec；如果最终主板支持稳定的 I2S 音频输出，可改为 I2S Codec/功放方案。

注意：BT 音频播放时，导航播报和 AI TTS 需要做音量 ducking。建议音乐音量临时降低约 12～18 dB，播报结束后恢复，而不是粗暴地停止音乐。

## 4. 麦克风与回声

麦克风不要与扬声器共用一个普通模拟输入链路。AI 对话期间需要 AEC（Acoustic Echo Cancellation），否则耀宝一边放音乐一边听用户，很容易把自己的声音当成用户说话。

推荐：

- 麦克风 → USB/I2S 数字音频输入
- Linux 音频层 → AEC/降噪/自动增益
- STT → Vosk 或后续云端 STT

## 5. GPS、Bluetooth、Wi-Fi 的物理布局

球体直径保持约 Ø100 mm 的 V1 尺寸时，建议：

- GT-U7 尽量远离功放、电感、电源升压模块和大电流走线。
- Bluetooth/Wi-Fi 天线靠近非金属外壳区域，避免被电池和金属件遮挡。
- 两个扬声器左右对称布置，形成独立声腔。
- 功放靠近扬声器，缩短大电流扬声器线。
- GPS 天线放在球体上半部或靠近显示窗口一侧，避免贴着电池。
- USB-C、按键、指示灯和麦克风孔保持现有后壳接口逻辑。

## 6. 关键电源注意事项

当前工程图中的 3.7V 2000～2500mAh 电池可以作为原型起点，但 Bluetooth 连续播放 + GPS + Wi-Fi + 屏幕 + AI 会明显高于纯导航待机功耗。量产前必须做实际续航测试。

功放不能直接接未经保护的锂电池。电池必须经过带过充、过放、过流保护的电源管理/充电方案，并根据功放实际输入电压配置稳压电源。

## 7. 软件模式

耀宝启动后默认开启 Bluetooth 可发现模式一段时间，屏幕显示：

`Bluetooth：耀宝-XXXX`

用户在手机系统 Bluetooth 设置中直接配对，不需要 App。

配对完成后：

1. 手机音乐 → 耀宝扬声器
2. 导航播报 → 自动降低音乐音量 → 播报 → 恢复音乐
3. AI 对话 → 降低音乐音量 → 麦克风监听 → TTS 回答 → 恢复音乐
4. 网络断开 → Bluetooth 音箱仍然可以正常工作
5. GPS 不依赖互联网，继续提供本地定位

这意味着 Bluetooth 音箱本身不依赖云端，是耀宝的本地基础能力。
